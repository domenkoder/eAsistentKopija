## Overview

This project recreates an eAsistent login page with separate views for:

- **Šole** (Schools)
- **Vrtci** (Kindergartens)

The page includes responsive layout behavior, tab switching, themed backgrounds,
different logos and page titles, login forms, and app-store badge images.

## Project files

- `index.html` - Page structure and content
- `style.css` - Layout, responsive styling, colors, transparency, and spacing
- `script.js` - Šole/Vrtci tab switching, logo changes, page titles, and form status
- `img/` - Images used by the page

## Running locally

No build tools or dependencies are required.

1. Open `index.html` directly in a browser, or
2. Serve the project with any local static file server.

For example, with Visual Studio Code, open the project folder and use a local
static-server extension to preview the page.
